# 예측 서버(ai_service) 실행 방법

PowerShell 기준입니다. 이 문서는 git 저장소 밖에 있습니다(커밋하지 마세요).

## 실행
1. 폴더로 이동합니다.
```powershell
cd D:\01-STUDY\dev\프로젝트\project3\project3\ai_service
```
2. 가상환경을 켭니다. (프롬프트 앞에 `(.venv)`가 붙어 있으면 이미 켜진 것이라 건너뜁니다.)
```powershell
.venv\Scripts\Activate.ps1
```
"스크립트 실행이 비활성화되어 있습니다" 오류가 나면 먼저 이 한 줄을 입력하고 다시 켭니다.
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```
3. 서버를 켭니다.
```powershell
uvicorn app.predict_api:app --host 127.0.0.1 --port 8000
```
`Uvicorn running on http://127.0.0.1:8000`이 나오면 성공입니다.
**이 창은 닫지 마세요.** 닫거나 `Ctrl+C`를 누르면 서버가 꺼집니다.

## 정상인지 확인
브라우저 주소창에 아래 주소를 열어 모델 정보가 글자로 나오면 정상입니다.
```
http://127.0.0.1:8000/health
```
- `"status":"ok"`, `"modelLoaded":true`면 정상
- `warnings`에 "예측 가능 기간이 곧 끝납니다"가 나오는 것은 12월 3일까지만 예측이 가능하다는 안내입니다.

## 막힐 때
| 증상 | 해결 |
|---|---|
| `uvicorn`을 인식하지 못함 | `python -m uvicorn app.predict_api:app --host 127.0.0.1 --port 8000` |
| `10048` (포트 사용 중) | 예전에 켜 둔 서버가 남아 있는 것입니다. 그 창에서 `Ctrl+C`로 끄고 다시 켭니다 |
| 이용자 차트에 안내 문구만 나옴 | 서버가 꺼져 있거나, `ai_service\.env`의 `PREDICT_API_KEY`와 `application.yaml`의 `py.api.key`가 다른 것입니다(두 값이 같아야 하고 16자 이상) |
| `.venv`가 없음 | `ai_service` 폴더에서 `python -m venv .venv` → 가상환경 켜기 → `pip install -r requirements.txt` |
| `.env`가 없음 | `.env.example`을 복사해 `.env`를 만들고 `PREDICT_API_KEY`에 16자 이상 무작위 문자열을 넣습니다 |

## 한 번 더 확인하는 순서 (발표 촬영용)
1. 예측 서버를 **먼저** 켭니다 (이 문서의 3번까지).
2. 그다음 Spring을 켭니다. 노선 혼잡 등급을 처음 계산할 때 예측 서버를 부릅니다.
3. 예측 서버를 켠 창은 촬영이 끝날 때까지 그대로 둡니다.
4. 이용수요 페이지에서 노선을 선택해 일별·시간대별 차트가 나오는지 봅니다.
