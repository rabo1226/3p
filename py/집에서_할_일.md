# 집에서 할 일: 관리자 지도 (ft/admin-map)

작성일: 2026-10-23
이 파일은 팀 저장소(git)에 올리지 않는 개인 메모입니다. (`3p/py` 폴더는 git 저장소가 아님)

## 0. 지금까지 확정된 것

- 브랜치: `ft/admin-map` (원격에 올라가 있음, 현재 `dev`와 같은 커밋 `f08564c`, 아직 코드 없음)
- 기술: Spring Boot 4 + Thymeleaf + MyBatis + MariaDB, 지도는 **카카오맵 JavaScript SDK** (REST API 아님)
- 키: **JavaScript 키 하나**면 충분. `application.yaml`의 `kakao.js.key`에만 넣고 git/대화에는 올리지 않음
- 노선 기준: **BIS 노선번호(BRTNO)**. 정류장 좌표와 순서는 BIS (`busStopInfo`, `allRouteDetailInfo`)
- 노선 선: 1차는 **정류장 좌표를 순서대로 이은 직선** (도로 경로 API는 약관 확인 후 선택)
- 예측 데이터는 가짜 데이터로 먼저 만들고, 나중에 실제 예측 결과로 교체

팀 DB 주소 `192.168.30.79` 는 학교 네트워크 안의 주소라 집에서는 연결되지 않습니다.

## 5. 만들 것 (진행 순서와 완료 기준)

## 6. 지도 동작 규칙 (팀 확정)

- 모드 2개: `top5`, `single`
- 처음 들어오면 **Top5 모드**: 혼잡 상위 5개 노선을 **흰색 테두리 + 등급 색**으로 표시, 순위 배지(1~5)
- Top5 모드에서 **지도의 노선 클릭** 또는 **목록의 노선 클릭** → **단일 노선 모드**로 전환 (그 노선만 표시)
- 단일 모드에서 **"Top5로 돌아가기"** → Top5 모드 복귀
- 두 모드 모두 노선을 클릭하면 **예측 상세 패널** 표시
- 선택 노선은 테두리(두 겹 선)로 강조, 겹침 처리는 2단계(흰 테두리) → 3단계(옆으로 벌리기) 순서로 필요할 때만

아직 정하지 않은 것: 목록 클릭 시 패널을 같이 열지, 단일 모드에서 빈 곳 클릭 시 동작

## 7. 코드 조각 (참고)

SDK 불러오기 (Thymeleaf, 키는 컨트롤러가 `kakaoKey` 로 전달):
```html
<script th:src="|//dapi.kakao.com/v2/maps/sdk.js?appkey=${kakaoKey}&autoload=false|"></script>
```

지도와 노선 선 (위도가 먼저!):
```javascript
kakao.maps.load(() => {
  const map = new kakao.maps.Map(container, {
    center: new kakao.maps.LatLng(35.5384, 129.3114), // 울산 중심 부근(대략), 위도, 경도 순서
    level: 8                                          // 숫자가 작을수록 확대
  });
  const line = new kakao.maps.Polyline({
    map, path: [/* LatLng 배열: 정류장 좌표를 순서대로 */],
    strokeColor: '#E53935', strokeWeight: 6
  });
});
```

## 8. 데이터 메모

- BIS 좌표: `STOPY` = 위도, `STOPX` = 경도 (지도 코드에는 위도, 경도 순서로 넣음)
- 한 노선번호에 방향이 2개 (예: 741번의 `BRTID` 2개) → 두 방향을 같은 색으로 그림
- 순환 노선은 시작과 끝이 같은 고리 모양
- 좌표가 빠진 노선은 537개 중 2개뿐, 선을 그리기 전에 걸러냄
- 정류장 간 거리 중앙값 약 400 m. 외곽은 간격이 커서 직선이 도로와 많이 어긋날 수 있음
- BIS 원본을 받아 둔 파일(이 PC): `3p/py/data/bis_stops.csv`, `bis_routes.csv`, `bis_route_stops.csv`
- 예측 결과 JSON 예시(예측 담당과 맞출 형식):
  ```json
  { "target_hour": "08",
    "top5": [ { "rank": 1, "rte_id": "31001340", "route_no": "134",
                "grade": "상", "predicted": 120, "vs_usual_pct": 12 } ] }
  ```
- 연결표 초안: `3p/py/data/route_crosswalk_v3.csv` (알려진 오류: 울주군 `3106` 계열 번호 규칙, 정류장 이름의 "앞" 표기 차이)

## 9. 막힐 때 점검

| 증상 | 확인할 것 |
|---|---|
| 지도가 안 뜸 | 브라우저 콘솔 오류, **JavaScript 키**인지, 도메인 등록(`http://localhost:포트`), 카카오맵 사용 설정 |
| 선이 바다에 그려짐 | 위도, 경도 순서가 바뀜 |
| 선이 뒤엉킴 | 정류장을 `BRSSEQNO` 순서로 정렬했는지 |
| 화면이 느림 | 노선을 한꺼번에 그리지 말고 선택한 노선만 불러오기 |
| 앱이 안 켜짐 | `application.yaml` 위치와 DB 연결(집에서는 팀 DB 접속 불가) |

## 10. 조심할 것

- 키(카카오, 공공데이터)와 DB 비밀번호는 **저장소와 대화에 올리지 않기**
- 커밋 전에 `git status`로 `application.yaml`, `.env`가 목록에 없는지 확인
- 팀 저장소에서는 새 파일을 만들 때 기존 폴더 규칙을 따르기
- 도로 경로(길찾기 API)는 **저장·재사용 약관 확인 전에는 쓰지 않기** (경유지 5개 제한, 자동차 경로라는 점도 고려)
