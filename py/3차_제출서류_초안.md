## 2. 개인별 직무수행평가표 (3차)

현재 3차 파일은 2차 내용(도시가스 지역 상세 페이지) 그대로입니다. 아래는 3차 기준 초안이며, 2·3번째 문항(부족한 점·칭찬)은 직접 느낀 바로 고쳐 쓰는 것을 권합니다.

**●각 프로젝트에서 본인의 역할과 수행한 내용은?**
버스 노선별 이용자 수 예측 시스템의 관리자 화면 중 '버스 이용수요(노선 정보) 페이지'를 담당했습니다. 카카오맵 위에 노선을 도로를 따라 그리고, 겹치는 노선은 옆으로 벌려 보이게 했으며 정류장 아이콘과 노선 선택 시 이동·깜빡임 효과를 넣었습니다. 노선별 미처리 신고 수와 이용자 수 예측을 한 화면에서 볼 수 있게 했고, 노선 1~2개를 선택하면 예측과 미처리 신고를 근거로 AI가 설명해 주는 기능을 구현했습니다. 또한 관리자 화면 전체의 색·글자·여백을 기준으로 정리해 화면별 틀을 통일했습니다.

**●프로젝트를 수행하면서 익힐 수 있었던 역량이나 기술?**
카카오맵 JavaScript SDK와 길찾기 API로 지도에 노선을 그리는 방법, 공공데이터 API를 직접 호출해 값의 단위와 한계를 확인하는 방법을 익혔습니다. 또 팀 저장소에서 브랜치를 나누어 작업하고 풀 리퀘스트로 병합하며 충돌을 해결하는 흐름을 반복해 익숙해졌습니다. 확인한 데이터로는 혼잡 등급을 신뢰성 있게 보여 줄 수 없다고 판단해 화면 범위를 다시 정한 경험을 통해, 데이터를 먼저 확인하고 기능을 정해야 한다는 점을 배웠습니다.
